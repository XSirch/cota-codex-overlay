# Cota Codex Android

Aplicativo Android pessoal para consultar a cota atual do Codex e o horário de reset usando o login do ChatGPT via device code.

- Login realizado em `auth.openai.com`.
- Consulta de uso em `chatgpt.com/backend-api/codex/usage`.
- Tokens armazenados criptografados pelo Android Keystore.
- Exibe todas as janelas de limite retornadas pela conta.

> Projeto não oficial, criado para uso pessoal.
